# 小小探索家 V5.1 · Mac 英语发音兼容性修复

### 本次改动
- 对全部 243 个英语课程词汇提供内嵌的美式英语离线备用音频（无需网络、无需安装声音包）。
- 声音小屋：默认“离线发音”；可手动选“Mac 系统发音”；分别试听 apple。
- 系统发音无法启动时自动切换到离线音频，避免英语游戏全程静音。
- 家长区词卡复用同一英语发音逻辑。
- iPhone/iPad/Mac、触控和键盘游戏维持原功能。

### Mac 排障
1. 点击顶部“声音”，确认“语音 开”。
2. 选择“离线发音 · 推荐”，点击“测试离线英语：apple”。
3. 若仍然没有声音，检查 Mac 输出音量、浏览器标签页是否静音，以及系统设置中的音频输出设备。
4. 若需要自然度更好的发音，切换“Mac 系统发音”并试听；系统音色能否发声取决于 MacOS 和浏览器。

### 隐私与限制
- 公开发布的依旧只有加密教材包和静态解锁页面。家庭密码、明文课程、英语音频不作为明文文件公开。
- 离线音频为本地合成备用发音，音色自然度有限；英语短句（非单词）以及中文语音仍使用系统语音。
- 本版已进行 Chromium 自动播放测试，真实 Mac Safari/Chrome 需用户设备端确认。

## V5.1 Mac 英语发音修复
- 243个英语课程单词提供内嵌离线 MP3 备用发音，不依赖 Mac 系统语音库。
- 声音小屋可切换离线发音 / Mac 系统发音，并分别试听 apple。

## V5.2 一屏儿童布局
- 儿童模式锁定当前视口，不再需要上下或左右滑动页面。
- 手机竖屏采用 2×2 游戏入口；平板和电脑采用 4 列入口。
- 游戏页面按剩余高度自适应；横屏小视口采用紧凑排版。
- 声音设置以浮层显示，不挤占游戏内容。
- 已验证 320×568、375×667、390×844、820×1180、844×390、1024×600、1365×768、1920×1080 等尺寸；包含答题成功、故事结局和声音设置状态。
- 页面资源仍只发布加密课程包；家庭密码和明文课程不上传。
