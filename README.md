# 小小探索家 V3 · 儿童优先版

## 课程体验
- 解锁后默认进入儿童乐园，适合 5—6 岁儿童；家长专区需要简单成人算式才能进入。
- 三个可实际操作的小游戏：汉字听音找字、英语听音找图、数学点击分饼干。另有逐页有声故事。
- 家长专区保留原有 41 周详细教案、识字与词汇追踪、学习记录、苹果日历 ICS 导出。
- 语音依赖设备可用的中英文 TTS 语音包，部分设备断网后可能没有声音；图文游戏仍可使用。

## 公开站点与隐私
- 此包仅包含解锁页面、AES-256-GCM 加密课程、PWA 缓存和图标。**家庭密码、明文课程、孩子的学习记录不在发布包中。**
- GitHub Pages 是公开网站：任何人都可访问解锁页、下载加密课程。此方案不是服务端账号鉴权，密码请勿公开。
- 保留原有家庭密码，密码文件不要上传 GitHub。
- 课程完成状态保存在浏览器 localStorage，不会跨设备自动同步；可以在家长专区手动导出/导入备份。
- 不使用第三方脚本、远程字体或统计服务。离线使用需要先成功在线加载并缓存。

## 更新 GitHub Pages
仓库已有 `.github/workflows/deploy.yml` 自动部署。更新根目录中的 index.html、course.enc.json、sw.js、manifest.webmanifest、icon.svg 等静态文件后将自动发布。观察 Actions 页面部署结果。
